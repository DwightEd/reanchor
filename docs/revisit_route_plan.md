# 回看节点与证据路径：验证实验实现约定

2026-09-11。回看是需要检查的计算事件，正确和错误回答都可能出现。
事件定位不以幻觉标签训练，也不以首错附近是否高分作为唯一成功条件。

项目分工：本文限定 reanchor 中的验证实验和候选算子。主线方法属于 graph 项目，
需要在那里接入原生提取、图算子、无监督评分和独立评价；本实验的实现与软件测试
不能视为完成了这项集成，也不能视为验证了自然数据上的检测效果。

## 一次完成的实现范围

1. `RevisitSignal.run()`：排除特殊符号、指令和 self，对共同可见的正文/历史
   分布计算 W1。保留原始权重，条件化只用于比较；历史中位数消除稳定顺读，
   历史分位数定位事件，输出起点与持续状态。头内归一化避免 sink 单独变化
   伪造内容移动，低正文质量不得被归一化成强证据。只用当前及过去。
2. `ReadingGraph.run()`：原生 attention 按 head 平均形成带层、时间、token 身份
   的有向图。直接来源与经历史 token 的 2..hops 路径分别计算，层数严格递减；
   历史 u 的输入行是 u+1。保留完整来源分布和图边，不只保存一个最大来源。
   图不含 V/O、MLP 或残差运算，称 attention 路径，不能称因果贡献。
3. `FixedPrefixStates.run()`：对原有 token ID 序列逐步前向，不重新采样；补取
   embedding、各层后的表征（最后一层按模型输出包含最终规范化）、完整 logits 熵、
   正文位置。核对原生 top logits、log-normalizer、attention 与原缓存，
   完成后按样本保存，重跑复用已完成且身份一致的状态。模型只加载一次。
4. `RouteReadout.run()`：对每层、每跳计算直接与历史路径的来源分歧；再用
   冻结的上下文表示读出关系保持残差。表征以同层源文均值中心化并归一化，
   内容对应由历史节点的实际路径和输入 embedding 相似性共同固定，不优化
   对应以迎合残差。比较生成 token 对的表示相似性与来源对应后的相似性。
   不把相似性、跨来源或高残差叫事实错误概率；没有有效路径时留空。
5. `WindowComparison.run()`：已有案例窗口只用于事后逐 token 数字对照，不输入
   事件或读出算法；保存 query、预测 token、事件、置信度、路径差异和关系残差。
   明确 label 的局部范围；未提供独立首错标注时不计算首错准确率。
6. 更新一键脚本：固定前缀状态补取 → 全流分析 → 六个实际窗口对照 → 推送
   文本结果。大张量保存在本地，不向 Git 推送；有样本进度和完成标记。

## 算子与限制

一跳 F[1,l,t,s] = mean_h A[l,h,t,s]。
k 跳 F[k,l,t,s] = sum_u mean_h A[l,h,t,P+u] F[k-1,l-1,u+1,s]。
只允许 u<t；其中 u=t-1 是当前 query 的较早层状态，没有使用未来 token。
prompt/source 是路径终点，不凭空补造原缓存中没有保存的 prompt 内部边。

来源对应 T(u,s) 正比于 F(u,s) exp(cos(e_u,e_s))，逐行归一化。
关系核来自同层源文中心化的上下文表征 x，B(i,j)=dot(x_i,x_j)。
对应后的核等价于 dot(sum_s T(i,s)x_s, sum_s T(j,s)x_s)。
对当前 query 到历史节点的读取，用正关系残差加权；同时保留每层、每跳读数。
这个无需关系标签的核是可检验的代理，不能预设其表达了对象—约束归属。
量词、否定、同词异义和合法跨句组合都可能成为反例。

## 验证接口与验收

使用现有 main(argv) 命令入口，以及三个数值算子的 run() 接口测试：
sink 变化不造成内容事件；稳定顺读与突然远读；正确/错误相同读取模式不影响事件；
完整两跳/三跳保留分叉；历史索引与未来不泄漏；相同熵但来源重接时关系读出改变；
无路径不可判定；真实微型 Llama 的采样→固定前缀→分析→窗口对照；断点重跑身份校验。
函数按实际算法阶段拆分，避免一个函数混合读取、计算、导出和评估。

本地缺少真实 16 条 NPZ 和 8B 权重，因此本地完成数值验证与微型模型端到端，
旧 CSV 只验证旧指标/时间定位。自然样本的新读出结论必须等待服务器执行，不能伪造。

## 实现与输出

上述六项已接通：`main.py states → revisits → compare`。
回看、图算子在 `src/decoding/reading_graph.py`，表征读出在 `route_readout.py`；
`revisits.py` 组织加载和导出，`fixed_prefix.py` 补取状态，`window_comparison.py`
进行独立窗口对照。算法不会读取 cases 文件。

`tokens.csv` 同时显示 query_step/query 和被预测的 token，active 是超过阈值的
持续区间，event 仅为区间起点。`layers.csv` 的熵是正文及历史上的条件熵，
不与旧全输入熵直接混比。W1 在两次前向共同可见的内容键上计算，score 再乘
两时刻较小的原始内容质量，避免极少量内容 attention 被归一化成强证据。

`paths.csv` 保存全部生成步、有效层、1..hops 路径的读数；sources 只展示前三个
端点，实际计算用全部端点。`graph.npz` 保存完整 head 平均图边及分跳来源分布，
不包含逐条路径的展开列表。原始逐 head 图仍在输入 NPZ；两者不能混称。
`--hops` 默认 3，最大有效值为模型层数。source 终止路径，不扩展 source 内部边。
大图 NPZ 与 hidden 状态留在服务器，Git 只推送文本和数字结果。

`comparison.csv` 对现有六个窗口逐步逐跳列出读数；层平均忽略无有效路径的层，
同时保留 valid_layers 与 relation_coverage。cases 的 start 是人工检查窗口起点，
offset 不是与首错的距离，judgment 即使存在也只描述窗口，不是逐 token 金标。

relation_shuffled 将 source 表征按位置循环移位，保持对应权重不变，是来源身份
对照而不是负样本；某些核对这种置换不变，因此不能要求该对照必然有差异。
软对应会稀释向量范数，关系残差也可能反映对应不确定性，必须与分歧和覆盖率
一起解释。表示关联是对称代理，不能保证表达量词范围或有向事实归属。

一键脚本会自动复用固定前缀状态；分析目录每次新建，按样本写中间文件，不承诺
逐 token 断点恢复。状态不一致或任一阶段失败时停止，不提交部分结果。
