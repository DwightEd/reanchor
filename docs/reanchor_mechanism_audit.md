# 回看后的关系选择：实验审计与主线

审计代码：37b554a；真实结果：58314cc 中的 `results/routes_20260911_091806_237`。
该结果提交已成功同步，37b554a 是其后的研究文档更新，不是另一次采样。
本次是实验能力审计与方案收敛，下面的事件检测和绑定检验尚未实现。
后续方法设计见 [关系保持读出](binding_readout_design.md)：先检验关系是否可读，再实现图上的关系比较；
本文件中的首错/回看检验属于定位与验证，不单独作为方法创新。

## 要检验的主张

**回看是重点检测窗口：模型在此重新组织对象、动作和证据，后续首次错误的风险可能升高。**
正确与错误回答都存在回看，不否定其定位作用。事件定义只用当前与过去；
研究的是事件之后的错误风险及其形成过程，不要求回看 token 本身已被标成幻觉。

进一步检验：有些错误由属性内容与对象/动作的适用关系没有保持而产生。
“数字在 source 中出现”“某 head 回读对象”“最后高度确信”均不直接回答这个关系问题。
对 Only 的泛化还可能是量词作用域/集合扩大，不能未经验证与对象交换归为同一机制。

## 优先修正的实验缺口

1. **固定距离门槛会排除关键回读。** `main.py` 中 inspect 的 `--min-distance` 默认 16；
   `src/decoding/attention.py` 只在达到该距离的 key 中展示 read/gain。
   实际 t128 的 query=662，历史 onions key=656，距离为 6；L7/H9 权重为 0.5078125。
   当前手工 decisions 保留了它，旧 inspect 默认不会展示它。节点定位应使用相对自身历史的变化，
   覆盖 source 和已生成历史，不以绝对距离 16 作为必备条件。
2. **人工窗口不能检验事件后的风险。** `RouteAnalysis.run()` 要求 focus 文本，
   `DecisionInspection.run()` 使用人工 start/stop；`analyze_cases.sh` 固定六个案例。
   这些作为事后放大镜保留，主分析必须先扫描全部回答、输出全部候选事件，再连接标签。
3. **当前 CSV 的两跳覆盖在正误例子之间不对称。** `decisions.py` 只导出指定 query 窗口。
   grill 历史 t85–87 的自身读取对应行 t86–88，但窗口从 t93 开始；simmer 的 t33–35 也类似。
   若从这些 CSV 重建历史承接的来源，会把缺测误作断路。下一次只补这些必要的 u+1 行，
   或直接从既有完整 NPZ 计算路径，不用扩大全部 CSV。
4. **attention 不能替代消息内容。** `sampling.py::_generate()` 只存各层最后 query 的 A 行，
   原生前向中的 prompt 其他行、Q/K、V/O 和中间 residual 未保留。A 的逆问题不唯一，
   不能从 A 和最终 top-5 反推出绑定信息或完整消息。补采采用固定序列前向，不重新抽样。
5. **当前 shift 会混淆顺序复制与读取重组。** `routes.py` 的 source 条件分布 TV
   不利用相邻 token 的距离，也不包含生成历史的重新分配。保留为基线，
   将既定 R_t 候选定义用于事件定位，并检查指令/sink、子词和正常条目转换。

25 个现有测试通过。它们检验数值、位置对齐、可见 key、实际抽样和 CSV；
没有检验事件后首错风险、绑定识别或干预恢复。软件通过与机制成立分别记录。

## 先把验证改成两个能证伪的问题

### 回看之后是否更容易首次出错

复用全部 16 条 NPZ，先计算无标签事件序列；WAAD、原 TV 和位置运输 R_t 用同样的输入比较。
参考样本与测试 source 分开，门槛、过去窗口和预测范围 K 在测试前固定。
评价是否存在 `0 <= first_error - event_step < K`，并单独标出提前量为 0 的同期检测。
只用首次错误尚未发生的窗口检验主风险；已有错误后的延续作为另一项解释分析。
非事件窗口匹配来源/长度/功能位置，保留正确回看、无回看的错误及未配对来源。
重叠报警合并为事件；按来源做不确定性统计，不能把相邻 token 当成独立重复。

新回答需要自己的标注，不能套用原 RAGTruth 其他回答的 span。
字符 span 的首 token 与语义关系首次越界位置分别保留，不用实体识别改写原标签。
FAI 可在同一固定未来范围内事后检查错误承诺是否被复用，不能成为当时的输入。
这一步验证回看的定位价值，不要求先确定因果路由，也不以熵高作为事件必要条件。

### 取出的内容是否保持原文中的绑定

先做最小的受控配对，随后用自然错误运行确认同类响应：

- **归属对照**：保留对象、动作、数值词汇集合，只交换两条明确关系中的时长归属；
  用相同问题及相同生成前缀测试原绑定和交换后绑定。改变来源次序但保持归属作为位置对照。
- **内容对照**：保持归属关系和位置，只改变时长内容。它用于区分“检索地址变化”和“读出数值变化”。
- 对 source 关系末端、自然回看窗口和首次关系承诺前后做层级扫描，先检查所有层，
  不把个别实例中峰高的 heads 当作预先已知的机制。Q/K 和 V/O 分开测量。
- 用已声明的两种关系续写，比较条件对数概率之差；多 token 续写用实际序列概率，
  不把长度不同的整句直接与单 token 分数混合。补丁首先比较同一接收前缀上的预测；
  若继续生成，再统一解码设置并对新的续写独立评价。
- 按 token 角色/边界对齐 donor 和接收运行，优先选分词长度匹配的对照。
  因果位置对齐不能用“两个例子都在 t128”替代；同 seed 也不等于同前缀。

受控对照是机制标尺，不是自然实验结果或部署时的实体列表。
原洋葱例子中的“啤酒煮洋葱 10–12 分钟”缺少依据，1–2 分钟属于另一动作，
不能把 1–2 指定为它的正确替换。对象已经在前缀固定后，只改数字也不能验证早先的对象选择。
必须分别检查组织关系之前和数字选择时，保留无法确定唯一正确续写的自然实例。

## 怎样回答“模型内部知道吗”

| 证据 | 支持到哪里 |
| --- | --- |
| 从原始错误运行的状态可泛化读出正确关系 | 正确绑定信息可读取；未证明生成时使用了它 |
| 固定接收端内容，只改 pattern/Q/K，注意力切换到另一绑定地址 | 该状态影响读取选择；还要检查答案是否相应改变 |
| 绑定干预同时按预期改变读取与关系续写，内容/随机/无关位置对照不复现 | 支持绑定对选择和下游输出有因果作用 |
| 外部正确 donor 修复错误运行 | 证明可修复，不证明原错误运行原本包含正确关系 |
| 某探针或补丁没有效果 | 不足以证明模型未编码关系；可能是位置、表示空间或干预方式不合适 |

绑定方向可以借鉴配对差分或低秩分析，但需跨对象、文档、位置留出验证。
它不能只记住第几个实体、数字身份或标点。诊断读出与最终无幻觉标签的方法分开；
若部署使用拟合的投影，就如实记录拟合步骤，不能同时宣称完全没有估计参数。

## 主方法只围绕这一条流程

    全序列的原生状态 -> 回看事件 -> 窗口内绑定的保持/失配 -> 后续首错定位

事件负责定位，margin/熵作为候选竞争的基线。机制检验只在少量配对样本进行，
不要求每条自然输入都做消融或提供已知实体列表。
图保留 `(layer, token)` 状态、source/history 身份、真实有序连接及 value 经 O 投影的消息；
它要追踪“对象/动作的信息如何约束属性路径”，不能仅比较是否回到同一个 passage。
已经验证的绑定读出才能成为图上的节点/消息信号，不能把未经验证的 cosine 命名为绑定分数。
图作用仍是冻结状态的分析读出；A 的路径乘积不能冒充包含 MLP、归一化和抵消的完整因果贡献。

与同样窗口、同样状态和相当读出容量的无边方法比较，主指标关注首错和误报警。
若图只复现 margin 或连续错误的后半段，就不支持结构优势；若窗口内绑定失配可泛化读取，
再固定图算子用于全流检测。当前尚不能承诺纯拓扑足以自动识别所有约束错误。

代码推进保持两步：先补现有 NPZ 的全流事件与必要历史行；再为固定窗口补原生中间状态及绑定对照。
继续复用 `main.py -> SamplingExperiment/DecisionInspection`，不增加通用配置、报告或 head 管理框架。
补采范围随检验需要确定，按 trace/层块保存数值；先核对原始 logits 和重建 A，再解释 Q/K/V 的差异。

## 可直接借鉴的研究

以下条目均已核对原文，并经 arXiv 元数据验证（verified via arxiv）。

| 研究 | 具体方法/结果 | 迁移及边界 |
| --- | --- | --- |
| [Oh & Demberg, 2026：Retrieval conditioned rebinding](https://arxiv.org/html/2606.08644v1#A1.F6)，预印本 | 改变 swap 对象，比较状态更新句末与 Answer 冒号处补丁；再拆 pattern 与 Q/K 的作用 | 将固定冒号迁移到自然回看/承诺窗口；Llama 的 K 响应不同于 Gemma，不能套用同一 Q/K 指纹 |
| [Feng & Steinhardt, 2024：How do Language Models Bind Entities in Context?](https://arxiv.org/html/2310.17191v2#S4.SS1) | 操作实体/属性两侧的绑定表示，检查改变一侧与同时改变两侧的差异 | 用“配对关系改变、词汇内容不变”的对照识别绑定信息；不是靠 attention 峰给角色命名 |
| [Dai 等，2024：Representational Analysis of Binding](https://arxiv.org/html/2409.05448v1) | 低秩表示分析和方向干预揭示位置相关的绑定编码 | 可以不训练新神经网络先找方向；需排除只读出顺序编号的捷径 |
| [Gur-Arieh 等，2025：Mixing Mechanisms](https://arxiv.org/html/2510.06182v1)，预印本 | 区分位置、词汇和直接指针三种检索机制，设计反事实分离其作用 | 长上下文可能混合多种方式；加入自由文本填充仍是受控任务，不能直接当自然 RAG 的证明 |
| [Geva 等，EMNLP 2023：Dissecting Recall](https://aclanthology.org/2023.emnlp-main.751/) | 研究 subject 富集、relation 传播及 attribute 提取 | 把对象、关系、属性的作用拆开测；原工作主要是参数事实召回 |
| [Yu 等，Findings EMNLP 2024：Non-Factual Hallucinations](https://aclanthology.org/2024.findings-emnlp.466/) | 中间 MLP/attention 的 logit-lens 与因果分析区分富集和提取失败 | 检验“表示存在但未被正确使用”；原实验知道正确对象，logit-lens 的负结果不等于知识不存在 |
| [Li 等，2025/2026：Attention Illuminates LLM Reasoning](https://arxiv.org/html/2510.13554v2)，预印本 | WAAD/FAI 描述组织与后续复用的节律 | 作为事件与事后 anchor 基线；不是错误标签 |
