# 回看窗口中的关系保持：方法设计

2026-09-11。状态：候选方案，尚未实现或验证。本轮只更新设计，不修改运行代码。
沿用 [研究要求](graph_method_proposal.md) 的事件定义、固定前缀控制与标签边界，
以及 [实验审计](reanchor_mechanism_audit.md) 的数据结论。

## 研究问题与创新边界

首错附近不确定性升高、错误前缀引发后续一致续写、在关键位置重新分支，均已有直接研究。
回看负责定位重点检查窗口；首错负责评价时间位置。这两项不再承担方法创新的主张。

本方案要检验的是：**内容分别被正确取回，但生成端把它们组成了源文不支持的关系；
这种关系失配能否通过内部状态及真实读取连接被读出，并在高置信续写之前或初期定位？**

“绑定错误”本身也不是新概念。候选贡献必须落实为可计算的关系读出、相对于单点置信度的增量，
以及在自然回答中经过控制的机制证据。公式换名、去掉 GNN 训练或增加图层数都不足以成立。

| 已核查的近邻 | 已经覆盖 | 本方案必须增加的证据 |
| --- | --- | --- |
| [Dissecting Failure Dynamics / GUARD，ACL 2026](https://aclanthology.org/2026.acl-long.401.pdf)，§3–4 | 数学推理的片段失效、熵变化、相同中间前缀重采样及选择性分支 | 具体关系如何在读取时失配；不能把首错熵与分支恢复重复作为贡献 |
| [First Hallucination Tokens，2025](https://arxiv.org/abs/2507.20836) | RAGTruth 首个幻觉 token 与后续 token 的区分 | 在相近置信度下，关系连接仍提供检测增量 |
| [CHARM，2025/2026](https://arxiv.org/html/2509.24770v2)，§3–5 | 带 attention/activation 的图与监督消息传递 | 无人工/伪造幻觉标签的明确估计目标；不是仅把分类器替换掉 |
| [SiGHT，AISTATS 2026](https://proceedings.mlr.press/v300/chen26d.html) | 出版摘要明确：合成幻觉训练、词级关系图、GAT | 不合成真假回答来训练分类器；关系标尺的监督来源必须如实说明 |
| [EGC，2026](https://arxiv.org/html/2606.06748v1)，§III | 问题、passage、句子之间的 embedding 图一致性；检测方向存在模型差异 | 读取 token 之间的配对关系，不能以语义相近或同 passage 作为支持 |
| [Retrieval conditioned rebinding，2026](https://arxiv.org/html/2606.08644v1#A1.F6) | 固定结构任务中的读取位置、绑定更新及 Q/K、pattern 对照 | 从预定变量的机制检验迁移到未指定实体的自然 token 流，并获得检测增量 |

GUARD 的 failure onset 使用 `\n\n` 分段和外部判定，不能等同于 RAGTruth 字符 span 映射后的首 token。
更近的结构语义工作还包括 [Li 等，ACL 2026](https://aclanthology.org/2026.acl-long.914/)；
其 attention 与 FFN 结果也说明，仅用读取拓扑不能替代语义落地的检验。
已有 [图/归因文献审查](graph_necessity_literature.md) 继续有效，旧 G0/G1 方案不因此恢复。

初步判断：**有条件继续，小规模验证；创新性尚未确立。**
检索未发现完全相同的读出，不构成“首次”的证明。关系度量学习、图关系映射与冻结传播各自均非新发明。

## 先收窄可处理的错误

首轮处理对象—动作—属性的错误组合，以及正常的证据转述、跨句回指。
洋葱实例是动机：源文出现了洋葱与 10–12 分钟，并不支持“啤酒煮洋葱 10–12 分钟”。
原文的 1–2 分钟属于黄油炒制，也不能设成这句的正确答案。

Only 的泛化可能涉及量词作用域；对称的配对归属读出不够表达所有此类错误。
该实例保留为边界案例，不将它硬归到同一个分数，也不先增加另一套模块。

## 核心读出：把源文关系映射到生成端再比较

保留全部 token 身份。令 S 是源文 token，Y 是截至当前已输入模型的生成 token。
第 l 层的上下文表示为 h，原生 attention 为 A。定义三个对象：

- T：生成 token 到源文 token 的内容对应；保留具体位置及实际读取路径。
- B_S：源文内部 token 对的归属关联。
- B_Y：当前生成前缀内部 token 对的归属关联。

先固定 T，再计算：

    B_supported = T B_S T^T
    E = positive_part(B_Y - B_supported)

逐项展开，`B_supported[i,j] = sum_(a,b) T[i,a] B_S[a,b] T[j,b]`。
它检查生成端 i、j 分别取回的来源 a、b 是否具有相应关联，而非检查两个词是否各自出现过。
禁止为了降低 E 再优化 T，否则可以把对应关系改到看似自洽而掩盖错误。
软对应只是期望支持代理，不是逻辑蕴含概率；多义来源与分散对应必须单独检查。

用当前 token i 对历史 j 的实际读取加权，形成一个读数：

    S_i = mean_(l,h) sum_(j<i, j in Y) A_(l,h)[i,j] * E_(l,h)[i,j]

先按层/head 形成对应和残差，再汇总；不按四个例子的正误差挑 heads。
R_i 表示读取重组，S_i 表示候选关系失配；margin/熵只作基线，不拼进另一串特征。
S 不是校准后的错误概率。无可用对应的位置应记为不可判定，不填零或当作正确。

一个理想化检验说明所需的信息：源文绑定 A—10、B—20。
正确生成保持这两对，错误生成改成 A—20、B—10；四个内容和各自出现次数均保持不变。
在准确的内容对应与归属矩阵假设下，正确配对 E=0，交叉配对存在正残差。
这两个配对图具有相同的节点度数与谱，需保留内容对应才能区分。
这是关于输入信息的条件性例证，**不是从真实 attention 自动恢复归属的证明**。

## 三个对象如何得到：不留一个假设中的“语义 oracle”

### T：冻结路径算子与内容对应

复用现有 graph 的有序 `(I+A)/2` 传播思想，节点信号改为源文位置的单位向量。
生成位置初始为零，每层按真实 attention 传播；source 行钳制为各自单位向量，
防止源文位置标签先被混成一个 passage。中间层按固定的 head 平均继续传播，
最后一跳保留各 head，得到非负的来源权重 Z。这个 Z 是冻结的路径代理，不是因果贡献。

内容核先用原模型输入 embedding 的固定相似度：

    C[i,a] = exp(cos(embedding(token_i), embedding(token_a)) / tau_c)
    T[i,a] = Z[i,a] C[i,a] / sum_b Z[i,b] C[i,b]

内容核不使用 B、不使用正确答案，也不从人工实体表筛选候选。
同词在不同源文位置仍是不同列。它可以处理软对应，但不保证同义、数值或多义词的正确对齐；
在校准留出集检查 token 对应，精确 token 匹配作对照，不能把核相似度叫事实支持。
Z 为零或对应未达到预先固定的可靠性标准时，此读出无判定；同时报告覆盖率。
不得把很小的来源权重归一化后包装成强证据。

上述逐层传播可写为 `Z_(l,h) = (Z_(l-1) + A_(l,h) Z_(l-1))/2`，
再钳制源文行并平均 heads，供下一层使用。它允许 source 经生成历史传递，
但不新增可训练 message/update 网络，也不把路径权重当作有符号的 V/O 效应。

### B：先检验低秩归属读出能否泛化

普通 hidden-state cosine、同一句、token 相邻或 attention 边都不能直接命名为 B。
提出一个具体且可否定的候选：用程序构造的独立关系文本估计低秩度量，冻结语言模型。
文本中交叉平衡对象、动作、数值、顺序和模板；程序知道哪两处属于同一关系，
不需要人为或 LLM 标注“这个生成回答是否幻觉”。校准包括源文与答案风格的前缀。

令 d=h_i-h_j。C_same 为同一关系内、不同角色 token 对的 `mean(d d^T)`；
C_cross 为角色和词汇边际匹配但不同归属 token 对的同类矩阵。
C_nuisance 由归属保持的次序/名称/表述变换，在对齐位置的表示差构造。
逐层解广义特征值问题，取前 r 个方向构成 P：

    C_cross v = lambda (C_same + C_nuisance + epsilon I) v
    B[i,j] = exp(-||P(h_i-h_j)||^2 / tau_b^2)

矩阵、秩和尺度只在独立关系校准集确定，随后冻结；不按自然测试集的幻觉标签挑选。
该形式倾向保留区分交叉归属、同时对同归属和无关变化稳定的方向。
它是已知度量学习思路的具体使用，**不是新理论，也没有保证真实模型存在这样的子空间**。
位置编码、词汇身份、跨角色表示不一致，以及答案状态未表达当前绑定，都可能使其失败。
尤其必须包含“同一对象的两个不同动作”：只识别同一个对象仍可能把两种时长混在一起。
对称距离核不保证表达三元关系；这一控制失败，就不能声称它解决了洋葱实例中的归属问题。
若模型的隐藏状态始终保留原绑定、只在最终输出中使用错误值，B_Y 也可能不显示正残差；
这种读出失败不能通过把置信度重新拼入 S 来解释成方法成功。

这是“无幻觉标签、程序化关系监督、闭式估计的读出”；不能称完全不拟合参数或严格无监督。
所估计的是关系读出矩阵，不是另一个生成模型或 GNN。
若保留“完全免拟合”作为额外硬约束，则第一版只保留冻结结构探针，
其归属识别能力仍待验证；不能略去 P 的来源来满足这个称呼。

先检验该子空间，再决定是否采用此候选。若只能读出第几个实体或只在固定冒号成立，
就停止此版本，不继续搭建图检测器来掩盖关系读出失败。

### 时间对齐

上式的 i 是已经输入模型的 token；其状态可用于监测下一步风险。
目前保存的采样行 t 的 query 为 `prompt_length + t - 1`，预测 y_t；
y_t 自身输入后的状态在行 t+1。不能把后者的失配读数写成 y_t 输出前的报警。
在具体内容尚未选择、两次运行前缀相同时，读出不能预知哪次抽样将出错。
后续关系形成的检测和早于首错的预警分别评价；自然首错前已有的失配才计作提前量。

## 图承担什么，以及怎样淘汰无用部分

T 使用实际 source→history→当前的连接，`T B_S T^T` 保留两个来源之间的配对关系，
当前历史边决定哪些已形成的关系正在被重用。图增加的是联合关系读出，而不是更多类别名。
这些运算属于冻结的分析模型，不能宣称比任意非图神经网络更有表达力。

同一 P、同一窗口、同一可用状态下做两个必要比较：

1. T 只用内容核 C，不使用路径 Z，并比较同 P 的节点读出。若结果不降，实际 attention 图没有证明必要性。
2. 固定内容对应、节点信息和原生置信度，仅在分析图中交换归属连接，
   使单点信息保持而配对改变。若读数不敏感，就没有读取主张中的关系。

另与当前候选方向 PathEncoder 比较；现有算子已能传播路径，
本方案新增的是“生成端关系与源文关系的对应检验”，不把旧路径算子重命名当创新。
如果原始节点读出或内容对应就足够，保留更简单的方法，图不作为论文前提。

## 最小验证顺序与停止条件

1. **关系读出门槛。** 构造独立配对文本：交换归属、只改数值、只换顺序/表述，
   同时留出对象、动作、模板和位置。先检验 B 与 T，包含正常多来源组合和功能词。
   归属改变须产生可重复的定向差异；仅次序/词汇变化不能产生同等大小的差异。
   该检验失败就停止当前 P/B 方案，不扩采数百条自然样本。
2. **自然样本检查。** 16 条已有回答是发现集；独立标注首错与关系越界，
   固定 token 序列补必要的 residual 与 source 内部状态。先跑全部 token，
   检查正确回看、错误回看、无明显回看的错误，以及高置信的错误续写。
   不让人工 focus 或已知出错对象参与事件/分数计算。
3. **独立来源验证。** 另取未用于设计的 source；固定 R/S 的规则和阈值后评价。
   只报首错召回、每条回答误报与提前/延迟，并注明无判定覆盖率；按 source 统计不确定性。
   在同样的报警预算、同样事件窗口下比较原生熵/margin、非图关系读出、现有图算子。
   无增量或收益仅来自连续错误后半段，则不支持主线方法。
4. **少量机制检验。** 对读数定位到的关系，固定接收前缀、拆分 pattern/Q/K 与内容补丁，
   检查关系续写是否按预期变化；有内容、位置与无关补丁对照。
   这是构念验证，不要求部署时每个样本做干预，也不将外部 donor 修复等同于原模型知道答案。

R 先作定位变量；首轮同时在非事件位置计算 S，避免先规定所有错误只能出现在回看处。
若 S 主要在内容输入后才上升，就如实定位为及时检测，不能包装成首错前预警。
后续 anchor 复用只作事后解释，不进入当时的分数。
